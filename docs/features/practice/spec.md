# Practice

The Practice screen lists the domains a learner can practise. A domain is the collection of levels for one
learning area, such as Walking the Dogs. Opening a domain shows its levels.

## 1. Domain titles

Each domain has a short English title (`name`) and its Slovene translation (`nameSl`) in its manifest.

| Domain id | `name` | `nameSl` |
|---|---|---|
| bakery | Bakery | Pekarna |
| butcher | Butcher | Mesnica |
| cafe | Café | Kavarna |
| demo | Demo | |
| lekarna | Pharmacy | Lekarna |
| library | Library | Knjižnica |
| restaurant | Restaurant | Restavracija |
| slavko-intro | Meet Slavko | Spoznaj Slavka |
| sprehod | Walking the Dogs | Sprehod s psoma |
| trznica | Market | Tržnica |
| upravna-enota | Administrative Unit | Upravna enota |

- `nameSl` is plain text. demo has no `nameSl`.

## 2. Domain cards

Each domain card on the Practice screen shows two lines and a "›" chevron:

1. the English title (`name`)
2. the Slovene title (`nameSl`), smaller and muted

- A domain without `nameSl` shows the English title only.
- The cards stay in their two groups, "Practice:" and "Example Conversations:".

## 3. Levels screen header

Opening a domain shows its levels under a header with the same pair as its card: the English title, with
the Slovene title under it in the same muted style. A domain without `nameSl` shows the English title only.
